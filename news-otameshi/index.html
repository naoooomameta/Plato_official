PHILOSOPHY

なぜ 9,900円 でお試しコースを
用意しているのか

プラトンの指導は、参考書の使い方から毎日の課題管理、保護者様への共有まで、講師と生徒・ご家庭の関係性で成り立っています。だからこそ、入塾前に「実際の指導はどんな手触りなのか」を確かめていただく時間が必要だと考えました。

無料相談だけでは、講師の話し方や、毎朝届く課題のリズム、丸つけの粒度までは伝わりません。一方で、いきなり入塾していただくのは、生徒さんにとってもご家庭にとっても大きな決断です。

お試しコースは、その間にある「もう少しだけ確かめてから決めたい」というお気持ちに応えるための、入り口プランです。1回のマンツーマン指導と1週間分の毎日課題を、本番と同じやり方でご体験いただけます。

WHAT'S INCLUDED

お試しコースに 含まれているもの

9,900円のなかに、プラトンの主要な指導要素をすべて凝縮しています。

01 — LESSON
60分のマンツーマン指導
指導7年目以上の専属講師が、オンラインで1対1の指導を実施します。志望校・現状の学習状況・苦手分野を伺いながら、参考書の使い方や勉強の組み立て方をお伝えします。
完全オンライン｜全国どこからでも受講可能
02 — PLAN
志望校から逆算した学習計画
初回指導の前後で、専属講師が志望校合格までの道筋を逆算した学習計画を作成します。「次の1週間で何をやるか」を具体的なレベルまで落とし込みます。
お子様＋親御様の双方に共有
03 — DAILY TASK
1週間の毎日課題体験
プラトンの目玉サービス「毎日課題」を1週間ご体験いただけます。毎朝5時までにLINE/Gmailで課題が届き、当日23:59までに提出。講師が丸つけ・解説をして翌朝までに返却する、本番と同じサイクルです。
朝の課題送付 → 提出 → 採点 → 返却
04 — FOLLOWUP
体験後のヒアリング・継続相談
1週間の体験を終えたあとに、専属講師から「お子様の様子」「次のステップとしておすすめの進め方」をお伝えします。継続するかどうかは、このタイミングでゆっくりお決めいただいて構いません。

A DAY WITH PLATON

お試し初日に起こること

60分の初回指導は、自己紹介で終わる時間にはしません。
実際にお試しを受けた高校2年生・Aさん（仮名・志望校：早稲田大学 文化構想学部）の初日を例に、当日の流れをご紹介します。

CASE — Aさん（高校2年生女子・早稲田志望）
「現代文の点数が安定しない」というご相談から始まった1日
20:00 LESSON START
志望校・現状・「困っていること」を15分でヒアリング
当塾がまずお聞きするのは、模試の点数ではなく 「何に困っているか」 です。Aさんの場合、河合模試の現代文偏差値は52前後で安定せず、特に 評論で時間が足りなくなる ことが悩みでした。志望校の出題傾向（早稲田・文化構想は記述比重が大きい）と照らし、どこにギャップがあるかを共有しました。
20:15 DIAGNOSIS
画面共有で、Aさん自身の答案を一緒に分解
事前に送ってもらっていた直近の模試答案を、画面共有で開きます。「設問を読む前に本文を全部読んでしまう」「設問の傍線部以外にメモが残っていない」といった 読解プロセスそのものの癖 を、講師が言語化してフィードバック。「自分でもなんとなく感じていた違和感が、はっきり言語化されたのがすごく腹落ちした」というのが、Aさんの初日の感想でした。
「『現代文が苦手』ではなく、『傍線部の前後20行に印をつける習慣がない』というレベルまで分解できると、明日からやることが見えてきます」
20:40 PLAN
次の1週間で取り組む教材と進め方を、その場で決める
Aさんには『現代文読解力の開発講座』を中心に、1日1題のペースで取り組むプランを提示しました。「何ページまでやるか」ではなく 「どこに線を引きながら読むか」「解いたあと、解説のどこを真似するか」 を具体化。ここまでで約40分。残りの20分は、保護者様も画面に入っていただき、ご家庭での声かけや進捗共有の方法をお伝えしました。
翌朝 DAILY TASK
初日の課題が、LINEとGmailに同時到着
翌朝5時、前夜に決めた内容に沿った課題が、お子様と保護者様の両方にLINE/Gmailで届きます。Aさんはその日のうちに評論1題を解いて23:59までに提出。講師が丸つけ・解説を入れ、翌朝5時までに返却。これが7日間、毎日繰り返されます。
※ご紹介したのは指導例の一つです。志望校・学年・現状によって、初日の進め方は一人ひとり異なります。
─ 1週間後、Aさんは通常コースへ移行されました ─

FAQ

よくある ご質問

お試しコースについて、お問い合わせの多い項目をまとめました。

9,900円は何に対する料金ですか？
1回60分のオンラインマンツーマン指導、専属講師による学習計画の作成、1週間分の毎日課題体験（課題作成・採点・解説含む）、体験後のヒアリングまでが含まれた一括の料金です。教材費や追加費用は発生しません。
本当に「初回限定・1回のみ」ですか？
はい、お試しコースはお1人様1回限りのご利用となります。お試し後に通常コースへの移行を希望されない場合も、再度お試しコースをお申し込みいただくことはできません。継続的なご相談は無料相談で承っております。
そのまま入塾しないといけませんか？
いいえ、体験後に入塾するかどうかは完全に任意です。「続けられそうにない」「他の選択肢も検討したい」と感じられた場合は、その旨をお伝えいただければ問題ありません。無理な勧誘は一切いたしません。
どのタイミングで始められますか？
常設のプランですので、年間を通じてお申し込みいただけます。お申し込みから初回指導まで、最短で3〜5営業日です。受験直前期や繁忙期は調整に時間をいただく場合があります。
対象学年は決まっていますか？
高校1年生から既卒生（浪人生）までを基本対象としています。中学3年生で「大学受験を見据えた早期スタート」を希望される方も受講可能です。文系志望の方を主な対象としていますが、迷われている段階でもご相談ください。
継続する場合、どのコースに移行できますか？
通常コースの全プランに移行可能です。お試しコース中の状況を踏まえて、講師から最適なプランをご提案します。移行時に入会金や追加費用が発生することはありません。
保護者も同席できますか？
はい、初回指導には保護者様にも同席いただけます。指導の雰囲気や講師の人柄を直接ご確認いただける時間としてご活用ください。毎日課題のやり取りは、お子様＋保護者様の双方にLINE/Gmailで共有されます。
お支払い方法は？
クレジットカード決済（Stripe）または銀行振込でのお支払いに対応しています。お申し込み後、決済リンクをお送りします。
お試しコース 細則
  • お試しコースのご利用は、お1人様1回限りとなります。
  • 料金9,900円は税込価格です。教材費・入会金は別途発生しません。
  • お申し込みから初回指導までは最短3〜5営業日。繁忙期は調整にお時間をいただく場合があります。
  • 体験期間中・体験後の継続入塾は任意です。無理な勧誘は一切いたしません。
  • お試しコースから通常コースへ移行される場合、入会金は発生しません。
